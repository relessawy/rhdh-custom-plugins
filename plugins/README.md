# Custom plugin source

This directory contains the eight custom plugins built by `scripts/build.sh`.
See the [custom plugin table](../README.md#custom-plugins) for their installation guides.

For **Argo CD, Topology, SonarQube, Dynatrace, PagerDuty, Service Mesh/Kiali and
Scorecard**, open [integrations/](../integrations/README.md). Each has its own provider
configuration and native/community package setup; these guides do not require a
separate custom implementation under this directory.
