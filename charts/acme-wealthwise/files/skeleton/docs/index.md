# WealthWise

WealthWise is ACME Bank's financial services demo. It contains four Quarkus services:
the web frontend, financial advisor, investment advisor and history service, backed
by PostgreSQL. Sign in using the environment's shared Keycloak realm.

Start from the application's RHDH page. Open Dev Spaces to edit and test the code,
follow the Jenkins build in CI, and check deployment in CD and Topology. This Docs
tab publishes the documentation from the same GitLab repository.
